A faster drop-in for make.fun's own makefun-site 1.0.0: builds the same static sites, byte for byte, in a fraction of the CPU time. Single-pass Markdown rendering with bulk HTML escaping, hand-written scanners instead of per-line regexes, ASCII fast paths for slugs, and templates rendered into arrays instead of concatenated strings.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=output node main.ts
```
